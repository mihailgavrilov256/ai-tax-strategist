# AI Tax Strategist

Годовой проект магистратуры направления «Искусственный интеллект» ФКН НИУ ВШЭ

## О проекте

Мультиагентная RAG-система для налогового консультирования

## Цель

Создать интеллектуальную надстройку над существующими открытыми налоговыми данными: multi-agent систему, которая умеет не только отвечать на фактографические вопросы, но и сравнивать юрисдикции, предлагать структуры оптимизации и объяснять свои рекомендации.
